# FOOTBOZE FUTSAL｜Instagram リール用 PV

東京・三鷹の育成年代フットサルクラブ **FOOTBOZE FUTSAL** の Instagram リール用 PV（30秒・縦型 9:16）です。

| ファイル | 内容 |
| --- | --- |
| `output/FOOTBOZE_PV_reel.mp4` | **完成版PV**。1080×1920 / 30fps / H.264 + AAC。そのままリールに投稿できます |
| `output/cover.jpg` | リールのカバー画像（1080×1920。中央に要素を寄せてあるので、プロフィールのグリッドで切り抜かれても読めます） |
| `output/overlays/*.png` | CapCut で実写素材に重ねる**透過テロップ**（全13枚、1080×1920） |
| `output/bgm.wav` | 自作BGM（120BPM・30秒）。コードで合成した音源なので著作権の心配はありません |
| `make_bgm.py` / `render_pv.py` | BGM と映像を生成するスクリプト（文言や色を変えて作り直すとき用） |

## CapCut での仕上げ方

完成版はそのまま投稿できます。チームの実写素材を入れたいときは、次の手順で差し替えてください。

### A. 完成版に実写を少し足す（手軽）

1. CapCut で「新しいプロジェクト」を作り、`FOOTBOZE_PV_reel.mp4` を読み込みます。
2. 上の表の時間に合わせて、実写クリップを**オーバーレイ（上のトラック）**に置きます。
3. 実写クリップの不透明度を 30〜50% に下げるか、ブレンドを「スクリーン」にすると、テロップを隠さずに雰囲気だけ足せます。

### B. 実写メインにする（本格）

1. プロジェクトの比率を **9:16** にします。
2. 実写クリップを表の時間どおりにメイントラックへ並べます（1クリップ 1〜2秒が目安）。
3. `overlays/` の PNG を、対応する時間のオーバーレイトラックに置きます。1080×1920 の透過画像なので、画面いっぱいに配置すれば位置は合います。
4. 実写の上で文字を読みやすくするには、クリップの「調整」で明るさを −15〜−25 くらいに下げます。
5. オーディオトラックに `bgm.wav` を置きます。0:00 から置けば、シーンの切り替えと音のヒットがそろいます。
6. 書き出し設定は「解像度 1080p／フレームレート 30fps」にします。

※ Instagram の楽曲ライブラリの曲を使いたい場合は、BGM なしで書き出して、投稿時に Instagram で曲を付けてください。

## 公開前に確認してほしいこと

- **実績の表記**: 「全日本ユース(U-18)フットサル大会 全国準優勝」「東京都ユース(U-18)フットサルリーグ 1部優勝」「OB 清水和也 選手（フットサル日本代表・FIFAフットサルW杯2021出場）」は、Web 検索結果と監督インタビューをもとにしています。都リーグ1部の優勝回数は情報源によって「2回」「7回」と食い違っていたため、回数は入れていません。
- **「練習参加 受付中」**: Drive にある練習参加型セレクションのフォームをもとにしています。現在も受付中か確認してください。
- **ロゴ**: 公式ロゴのデータが見つからなかったため、文字でロゴを組んでいます。公式ロゴがあれば、CapCut で 0:03–0:06 と 0:27–0:30 に重ねて差し替えてください。
- **チームカラー**: 公式 Instagram / X のアカウント名にある 🟠 から、オレンジ × ブラックにしています。

## 素材について

- チームの写真・動画は、今回の作業環境からは公式サイトや Instagram に接続できず取得できませんでした。そのため、実写を使わないモーショングラフィックスで構成し、実写を後から足せるよう透過テロップを用意しています。
- Google Drive にあった Instagram のデータエクスポートは個人アカウントのもの（DM を含む）だったため、PV の素材には使っていません。
- フォント: Dela Gothic One / Anton / Bebas Neue / Noto Sans JP（いずれも Google Fonts・SIL Open Font License）。`render_pv.py` を初めて実行したときに `fonts/` へ自動でダウンロードされます。
- BGM・効果音・ボールやコートの図形は、すべてスクリプトで生成しています。

## 作り直すとき

```bash
pip install pillow numpy scipy imageio-ffmpeg
python3 make_bgm.py      # output/bgm.wav
python3 render_pv.py     # mp4 / cover / overlays（約2〜3分）
python3 render_pv.py --stills   # 確認用の静止画だけ書き出す（数秒）
```

文言は `render_pv.py` の各 `scene_*` 関数、色は冒頭の `ORANGE` などの定数で変更できます。
